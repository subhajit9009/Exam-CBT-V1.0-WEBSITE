Important: Mark for Review

If you select an answer and click Mark for Review, the question will remain marked for review when you return to it later. A small green check indicates that an answer has been selected.

An Answered + Marked for Review question is still evaluated normally. A correct answer receives its positive marks, while a wrong answer receives the applicable negative marking.

If a question is marked for review without an answer, it remains unattempted and receives zero marks.

Use Clear Response to remove the selected answer and review status. Selecting a new answer afterward makes the question Answered.
